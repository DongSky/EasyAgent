# 扩展系统与短板补齐执行计划

2026-09-20。按用户授权自主开发；仅维护集成测试，无 Docker。以 `earendil-works/pi` 提交 `3c75b2747965e8d69ad9e17cbe788b2e33bf4d99` 的 coding-agent 扩展 API、core 事件及 Chord 服务/生命周期为功能对照。目标是能力对等和语言无关协议；不承诺直接运行导入 Pi TypeScript API 的包。

## 交付顺序

1. **E1 扩展契约和宿主**：版本化 Manifest、JSON Schema、工具/模型/命令/服务/事件/状态/UI/Skill/提示模板贡献；Python/JS/Rust 进程协议；依赖检查、注册冲突、激活/停用/升级/回滚、运行固定版本、错误隔离和超时。保持现有工具插件兼容。
2. **E2 扩展产品入口和分发**：源码包、摘要/签名/信任、安装预览、权限与运行条件、依赖锁；开发脚手架、REST/OpenAPI/SDK；同一目录供画布与自然语言构建发现。UI 扩展采用声明式表单/面板和受隔离的自定义视图，通过有约束的命令桥调用后端。
3. **E3 持续会话**：持久 Conversation/Turn、原始消息、转向/后续队列、取消、分支、摘要及来源、搜索、模型流式事件；扩展可以接入会话和上下文生命周期。
4. **E4 学习与协作**：来源明确的记忆增删改、经验/Skill 候选、执行评估后发布/回滚；动态子 Agent 权限收窄、消息、wait/cancel/result、成本/数量上限及重启续接。
5. **E5 实际办事与连接治理**：可配置消息/日历连接器、持久 outbox、投递回执与重试、时区定时；MCP 长连接、动态发现、健康状态、OAuth/刷新；连接中心管理密钥且分享包只带引用。
6. **E6 代码与跨平台**：无 I/O 默认权限的受控 JS/WASM；不可变源码/依赖包、试跑、发布；完整 Python/Node/Rust 插件仅在明确受信任或隔离的兼容执行器执行。共享 Rust 状态机/Host 契约、Android/iOS 宿主与发行构建。
7. **E7 运维与验收**：诊断、备份恢复、可观察事件/指标、安装启动入口；故障注入和长稳任务。真实新手实验、72 小时测试、手机真机/签名发行需分别取得证据，不能用接口或编译通过代替。

## E1 / E2 接口原则

- 所有公共对象 `schema_version=1`，未知字段拒绝；统一 ID、版本、输入输出 Schema、错误、取消和事件序号。
- 扩展钩子不能扩大 Agent 工具、模型、开发授权、预算或跳过审批；修改参数后重新校验，审批绑定实际参数。
- 运行快照固定扩展版本；热更新影响新运行。旧版本仍可恢复，停用阻止新调用，卸载不能破坏在途运行。
- 生命周期、服务和 UI 后端操作均有时限和结构化回执；有副作用的服务通过工具审批路径，不直接从 UI 绕过。
- 本机源码进程属于受信任代码；环境变量筛选和 subprocess 超时不是 OS 沙箱。无信任不得激活进程代码；声明式和受控计算可单独启用。
- 发布者签名验证身份/内容，不自动授予权限；摘要不等于身份认证。凭证不进入源码包、日志或模型上下文。
- 状态使用 revision/CAS 和可重放事件，服务消费者不直接持有可变注册表；UI 与后台共享 schema，而非重复业务逻辑。

## 集成验收矩阵

- 三种语言扩展安装→贡献发现→画布/自然语言目录→实际调用→升级→旧运行恢复→回滚→重启。
- 钩子改写、拒绝、超时、错误，以及工具参数改写后的 Schema/审批/allowlist；不接受声明成功冒充执行。
- typed service RPC、依赖循环/缺失、CAS 冲突、并发与状态事件恢复；模型 provider 与自定义 UI 命令。
- 包篡改、签名/信任、路径越界、凭证泄漏、权限扩大、版本冲突和原子安装。
- 多轮会话中断/转向/分支/摘要/重启；真实 HTTP SSE 分片与工具参数流式组装。
- 学习候选→测试失败拒绝→通过发布→其他会话复用→回滚；子 Agent 消息与父子崩溃恢复。
- 连接断开、OAuth token 过期、工具列表变化；通知失败与任务成功分开记录；时区和重复事件。
- 代码运行资源限制、网络/文件越权、取消、可分享源码、跨运行器一致性；移动端构建与真机证据分别记录。
