# 工作室界面迭代

目标：先让用户找到要做的事，再展示完成这件事需要的配置。完整代码、画布和自然语言三种构建方式共用原有执行与分享接口。

## 导航与功能去向

- **我的助手**：助手与流程列表、搜索、最近任务；创建助手下可描述需求或打开画布。导入、导出、分享与子流程复用保留。
- **对话**：历史搜索、创建与继续对话、修改名称/模型/要求、追问、补充要求、分支、停止、整理上下文、扩展视图。
- **任务**：执行记录、结果/文件、待确认与补充材料；二级入口管理定时任务与外部事件。
- **资料**：资料库导入与搜索；二级入口管理长期偏好与查看变更历史。
- **设置**：模型与服务、扩展能力、经验改进、策略验证、诊断备份、开发接口。低频配置从设置首页进入，各子页有返回路径。

## 交互原则

1. 左侧仅保留五个主入口；手机使用同样五个底部入口。当前页面、浏览器前进/返回和链接地址一致。
2. 创建时先描述需求，生成后显示实际步骤，再输入材料试运行；未生成时明确说明下一步。
3. 画布顶部固定放置运行/保存；添加步骤、节点库、文件分享各有独立区域。条件、重试、原始 JSON 保留在高级设置。
4. 用户界面使用“资料”“记住的偏好”“保存结果”“定时任务”等名字；模型 ID、节点 ID、接口地址作为需要时可见的技术详情。
5. 表单主动展开，后台刷新不得覆盖正在编辑的配置。外部操作仍由运行系统的实际权限与确认约束。
6. 空列表只说明当前状态，并在需要时提供操作按钮；状态用中文；诊断先展示结论，再提供原始数据。
7. 简化入口不删除能力，不假装支持尚未实现的平台或执行能力。

## 验收

- 桌面与窄屏逐页检查，主导航不溢出，对话侧栏不覆盖全局导航，弹窗可关闭。
- 三种构建方式可达；保存流程、运行、查看结果、导出、分享、导入路径可用。
- 对话设置与原有对话流程、资料保存/检索/偏好历史、服务与扩展配置使用真实接口。
- 浏览器返回恢复路由；筛选后无结果有提示；表单编辑中不被刷新重置。
- 运行现有集成测试和 JavaScript 语法检查，记录浏览器验收结果。

## 实施记录

2026-09-20 已完成本轮迭代。

- 主导航从 12 个入口收敛为 5 个，旧页面保留在二级导航与设置分组；支持链接定位、前进/返回和明确的返回按钮。
- 首页新增助手/流程切换与搜索、最近结果、全量待处理/执行中统计。待处理卡片会进入相应任务筛选。
- 创建页面按需求、步骤、试运行组织；模板只填充需求。保存后的真实工作流继续支持预览、编辑、导出项目和分享。
- 画布将名称、检查、保存、运行放在顶部；能力库和技术参数按需展开。内置工具、字段、类型改为中文显示，协议 ID 保持兼容。
- 对话增加可编辑设置（标题/模型/要求/回复长度）；保存每个对话的页面内草稿；修复内嵌侧栏使用全局固定定位的问题。
- 服务连接按功能展开，取消定时刷新表单；补充已连接模型清单和外部消息通道配置。MCP 权限在各连接的详情中设置。
- 偏好增加合并与原文历史；服务端可选返回值摘要，合并时检查是否有并发编辑，冲突时保留原文。
- 任务名称与状态在服务端筛选，再截取最新 100 条匹配结果，避免只搜索已加载的列表。新增接口参数为可选项，旧客户端不受影响。
- 扩展的版本、分享、状态与事件放入详情；诊断先展示数据库、工作进程、任务与投递数量。
- 375/390 像素宽度使用底部导航。修复长流程 SVG 对网格宽度的撑开，画布和预览在自己的容器内滚动。

## 文案精简（2026-09-20）

页面只保留功能名称、操作、状态和影响用户决定的说明。移除品牌口号、主页宣传横幅、欢迎语、重复介绍和无具体作用的引导。空状态使用“暂无助手”“暂无消息”等名称，成功提示只报告结果。操作示例保留为可点击的入口。

费用、权限、附件去向、输入限制、版本及错误恢复等提示仍保留，放在相关操作附近。帮助文档集中解释用法，避免每个页面重复教程。此规则同时适用于对话、助手、画布、任务、资料、设置、扩展、Skills、弹窗和生活管家示例。
