# 运行与安全边界

默认监听 127.0.0.1。配置 bearer token 后 SDK/API 使用 Authorization；不允许无 token 绑定公共地址。浏览器示例使用当前用户本地服务，token 只保存在当前页面内存。

SQLite 使用 WAL、busy timeout 和短事务。数据库放本地磁盘，不支持网络共享文件系统上的多主部署。按需备份必须使用 SQLite backup API，不能只复制主文件并遗漏 WAL。只记录可解释的输入输出与事件，不记录模型隐式思维链；业务数据和模型输出可能含隐私，应限制数据库文件访问。

## 故障语义

- 未领取：保留 queued，重启后继续。
- 运行中进程崩溃：租约到期后重新领取；旧 worker 不能提交。
- 可重试错误：有界指数退避；超过尝试次数则失败，依赖步骤跳过。
- 写操作不确定：needs_attention，用户核验后提交结果或终止，不自动重复扣款/发信。
- 审批：批准关联具体调用参数；修改参数是新的调用，不能复用其他操作的许可。
- 取消：停止调度，取消本地等待；无法撤销已经由外部系统接受的操作，需查回执。
- 模型调用：超时、有限轮数与输出；不承诺 token 费用严格等于估算。

## 信任边界

插件 manifest、Python 扩展、MCP 地址与模型配置由部署者提供。进程插件可访问同一用户的操作系统权限，**不是沙箱**；不可信纯计算使用受限 JS/WASM；其他源码应由受信任账户或独立系统隔离环境承担。本方案不使用 Docker。环境白名单和超时降低误用，但不能替代隔离。

外部材料、工具结果和 Skill 正文不能更改框架权限。write 工具审批由内核执行。Skills allowed-tools 不授予额外权限。模型可在显式 development 授权内创建/更新 HTTP 节点和工作流；不能自行增加权限、安装本机插件或修改 active policy。Self-evolve 只能修改显式策略字段；评估通过后仍需由 API 用户批准。

0.1 是单用户本地开发预览，有本地加密凭证库和通知投递队列，不含账户系统、云端租户隔离或长期运行 SLO。跨平台 CI、长稳压测、灾难恢复和真实连接器验收必须在生产上线前完成。

## HTTP、搜索与运行预算

普通 HTTP 入站限制实际请求体 2 MB，包括无 Content-Length 的分块传输。仅原始 `/v1/artifacts/upload` 上传允许 50 MB，仍执行认证和同源校验。普通 HTTP 工具响应限制 1 MB、不跟随重定向，默认 30 秒超时，凭证来自服务端进程/环境。API 错误不回显供应商响应体或带凭证 URL。持久连接使用 `--config`，模型连接和连接中心凭证已持久保存；临时 API 密钥应转存连接中心别名；详见 [搜索与 API](SEARCH_AND_APIS.md)。

Workflow 的模型调用、工具调用、输出 token、子运行数和时间预算由内核统计，子流程与父流程共享总限制。费用预算需要配置实际模型价格；未知价格时不能声称已限制费用。搜索等外部工具费用不计入 LLM cost_usd，需另用 tool_calls 和供应商账户配额控制。

## 诊断、备份与维护

工作室「诊断与维护」读取实际队列、数据库、进程、连接和投递状态。`GET /v1/operations/metrics` 是 Prometheus 文本；`GET /v1/operations/traces/{run_id}` 返回该运行的事件和模型调用记录。

`easyagent doctor --database .eah/hub.db` 检查本机状态。备份通过 SQLite backup API 生成一致快照，包含解密凭证所需的 `.secrets.key`，整体使用密码派生密钥加密。界面可下载，CLI 也可执行 `easyagent backup --help` / `easyagent restore --help`。恢复仅允许新的数据库路径，禁止覆盖在用数据库；密码不写入数据库和分享包。密钥文件与数据库同机，不能防御整个操作系统账户被控制。

后台自动摘要默认关闭，需明确启用；复盘模型/每日额度默认关闭。候选不会自动发布。任务内有 `learn_as` 才进入复盘队列；计费按实际配置模型。

最新短稳：600.05 秒、5,518 个运行、55 次重启、0 失败。`scripts/soak.py --seconds 259200` 提供 72 小时运行入口，本次尚未运行该关卡。多进程可执行持久队列；扩展管理只由一个宿主管理，其他执行宿主需重启加载注册表。

移动端范围见[移动端策略](MOBILE_RUNTIME_STRATEGY.md)。手机不启动 Python Hub 子进程或 Docker；完整长任务由用户连接的 HTTPS Hub 承担。
