# 三种完整开发入口

完整操作与开发主文档：[使用指南（中文）](USER_GUIDE.zh-CN.md) / [User guide](USER_GUIDE.en.md)，[开发指南（中文）](DEVELOPER_GUIDE.zh-CN.md) / [Developer guide](DEVELOPER_GUIDE.en.md)。本专题保留构建方式与历史验收细节。

三种模式共用持久化内核、权限检查、模型注册表与 Workflow 契约。不是互相独立的 demo。

三种入口均支持[完整工作流分享](WORKFLOW_SHARING.md)：零代码结果/低代码画布提供下载入口，Python/JS/Rust SDK 提供同一包的导入导出方法。接收端绑定自己的模型、凭证和外部依赖后得到可编辑的独立流程。

## 零代码：Studio 创建助手

运行 `uv run --extra app easyagent studio`，连接模型后填写需求，点击「生成工作流」。模型根据已接入的能力自动选择 API、模型、Skills 和资料库，生成实际步骤、依赖和数据引用。零代码用户不需要填写工具、策略、Skill 等技术配置。缺少必要能力时显示缺少条件；默认 mock 不参与自动构建。设置中保存的模型连接与 API key 进入本机加密凭证库，重启恢复；通过配置文件注册的连接仍按其部署配置加载。

生成结果以节点连线、中文步骤说明和完整定义展示，保存后可以重复运行。预览、运行与导出共享同一份 Workflow；修改需求后必须重新构建。ZIP 包含 assistant.json、workflow.json、input.json、WORKFLOW.md、dependencies.json 和 Python/JS/Rust 的执行入口。三个入口都会提交并等待结果，遇到审批/补充信息则输出暂停状态。模型和工具在 Hub 服务端配置，导出项目是 Hub 客户端，不包含密钥、模型权重或独立服务器。

「连接模型」测试成功后自动关闭；测试中可点击顶部/底部关闭或按 Escape。测试失败时保留可修改的表单，不占用连接名称，可修正后重试。

## 低代码：Studio 编排流程

通过表单新增十种节点（包括模型、工具、Agent、检索、产物、循环、子流程、补充信息等）。依赖关系决定先后/并行；参数 JSON 可包含 `$ref` 数据映射；条件 `source + equals` 决定执行或跳过；可以单独要求执行前确认。循环体可以选择已保存流程，也可直接编辑。

流程可以保存、导入、导出、运行，保留初始输入、预算及元数据；同一 JSON 可交给三个 SDK。可拖动节点、拖拽或点击端口连接、断线、撤销重做、平移/缩放/自动排列；输入输出类型匹配与循环依赖有前端检查，服务端还会检查 Workflow/schema。布局保存在 metadata.editor。条件支持等值分支，循环支持有界数组 foreach；尚不支持任意脚本表达式或无限 while。

节点卡片自动展示工具输入/输出字段；常见类型可直接用表单填写。复杂 schema、子流程和重试等配置保留高级编辑器。自由对象允许扩展字段，静态类型不完整时最终仍由运行时 schema 校验。

自动生成的流程可打开到同一节点画布；画布修改后另存为低代码流程，当前不自动覆盖原助手的生成版本。

## 跨入口验收

2026-09-19 浏览器实测：使用已连接的 gpt6 生成「提取通知 → 转为文本 → 整理清单 → 保存文件」四步流程，并实际执行、生成文本产物。低代码已验证 input 节点暂停、补充信息和恢复。集成测试核对预览/导出/执行图相同，实际运行导出包内的 Python/JS/Rust 三个入口，检查需求修改、缺少能力、非法参数、显式写操作审批与子流程导出。

这验证了入口可运行。源码安装需要 Python/uv；已有 macOS 本地开发构建，尚无已公证的公开桌面安装包；5–8 位新手的无指导任务测试、可理解性访谈与首次成功耗时，仍是后续易用性关卡。

## 代码：Python / JavaScript / Rust

调用已有流程时，推荐使用三个 SDK 的 `workflow(id).start(inputs)` 和 `result()`，按业务参数提交并读取命名输出。流程定义、子流程版本、模型协议和轮询配置由作者集中维护；调用者仍可读取完整定义或使用底层请求。完整示例见[三种语言生成图片和视频](../examples/getting_started/media/README.md)。

- Python：`easyagent_client.HubClient` 调用服务；`Hub` 嵌入运行；异步 Tool handler 和 ModelProvider 可扩展内核。
- JavaScript：`sdk/javascript/index.js`，附 TypeScript 声明，无额外 npm 依赖。
- Rust：`sdk/rust` crate，含类型化入口、通用 JSON 请求和原生插件示例。
- 语言无关插件：manifest + JSON stdin/stdout；Python、JS、Rust demo 使用相同协议。
- MCP：通过官方 SDK 接入或暴露工具；Skills：目录发现和选中时加载正文。

## 扩展但不分裂

希望复杂助手易于开发，关键是减少用户必须一次理解的概念。零代码用户先认识需求、工作流预览、运行与确认；低代码用户逐步接触步骤、依赖和条件；代码用户可看完整请求、事件、数据库状态和协议。错误与审批沿用同一运行记录，不在某个入口里隐藏失败。
