# 默认生图与视频节点

新工作区的「画布编排 → 从能力库添加步骤」默认显示五个媒体节点。它们来自项目已经实现并测试的协议；不包含作者的服务地址、密钥、私人附件或固定角色提示词。

- **文字生成图片**（`library.media.image_generate`）：提示词生图。输出 `result` 与 `artifacts`；Base64 图片自动保存为文件，服务返回 URL 时保留原链接。
- **参考图生成 / 编辑图片**（`library.media.image_edit`）：接收原图文件 ID，通过 multipart 传给编辑接口，原图保留，成品作为新文件返回。
- **生成视频 · 提交任务**（`library.media.video_submit`）：文字或参考图生成视频，返回任务回执。
- **生成视频 · 等待结果**（`library.media.video_wait`）：接收任务 ID，持久查询到完成，返回视频地址。等待释放运行资源，重启继续查询，不重复提交。
- **上传参考图为 HTTPS 地址**（`library.media.image_upload`）：用于需要公网参考图地址的兼容视频服务。上传和视频生成分别确认；服务必须提供该上传协议。

这些都是独立节点。上传、提交、等待组合起来才是一条工作流；默认不会给新工作区创建演示任务或测试子工作流。

## 连接后使用

1. 在「设置 → 模型与服务」保存自己的服务连接。
2. 打开能力库，点击对应默认节点的「选择服务连接」，选择已有连接，并填写该服务实际提供的模型 ID。也可从此窗口跳转添加连接。
3. 连接只保存和验证配置结构，不发起生成或上传。视频提交节点会同时配置独立的等待节点。
4. 点击「加入画布」填写提示词、图片文件 ID 等参数；也可以回到原对话，让 Agent 从新增工具目录编排。节点无需用户编写输入输出 schema。

服务地址、密钥、账户权限和模型可用性仍由使用者提供。默认显示“待连接”表示协议已经支持，不表示任意文字模型服务都支持图片、视频或上传。绑定时模型 ID 可修改；图片示例默认 `gpt-image-2.5-flare`，视频示例默认 `doubao-seedance-2-5-260628`，不是对其他服务的模型可用性保证。

默认图片编辑和参考图上传节点允许 multipart 文件合计 50 MB，与本地附件存储上限一致；服务端仍可能有更低的限制。其他 HTTP 节点的 `max_upload_bytes` 默认 10 MB，可配置到 50 MB。JSON 内联媒体仍限制 10 MB。已绑定的旧版节点需重新绑定以创建新版本，旧工作流保留原版本。

发送前的文件大小、附件或参数检查失败会明确显示“请求未发送”，不会要求核验外部结果。请求发出后出现断线、超时或无法确认结果时，仍暂停并保留核验入口，避免重复生成。

HTTP 413 表示服务拒绝了过大的上传，会显示明确错误。App 随附本地工具 `attachments.prepare_image`（独立 SDK 可安装 `easyagent[media]`），把原图生成最长边默认 3072 像素、默认不超过 1 MB 的 JPEG 上传副本，完整保留原始附件。将返回的 `artifact.id` 传给编辑节点，将 `original.id` 用于关联原图。压缩和修图分别是可见步骤；透明区域会填为白色，这个工具本身不做修图。

接口路径为 `/v1/images/generations`、`/v1/images/edits`、`/api/v3/contents/generations/tasks`、`/api/v3/contents/generations/tasks/{id}` 和 `/openapi/v2/image/upload`。基础地址结尾 `/v1` 会按这些协议处理。上传协议与视频协议不同，不能因为服务支持视频就假定它也支持上传。

## 参考图动画连线

将 `image_upload` 的 `result.Resp.img_url` 连到视频提交参数 `content` 中的 `image_url.url`，设置 `role="first_frame"` 和 `ratio="adaptive"`。也可以直接使用服务支持的 HTTPS 图片地址，或在服务明确支持内联图片时传入原图文件 ID。

将视频提交返回的 `result.id` 连到等待节点的 `id`。有些兼容服务把任务号放在 `result.data.task_id`，应按真实回执选择路径。等待节点接受 `pending`、`queued`、`running`，成功时返回 `content.video_url`。收到任务 ID 只代表提交成功，不能当作视频已完成。

结果链接可能过期。`generate_audio=false` 是否被上游遵守，必须看实际回执；先前真实验收遇到过服务仍返回音轨的情况。历史证据与协议差异见[媒体验收记录](MEDIA_ACCEPTANCE.md)，完整脚本组合见[媒体示例](../examples/getting_started/media/README.md)。

## 版本与凭证

绑定产生普通的固定版本 HTTP 节点，支持组件导出，导出不包含密钥。密钥在本机加密保存并与原服务连接关联。修改或删除服务连接会停用其派生节点；重新绑定创建新版本，旧工作流不会把旧凭证发送到新地址。引用连接的未完成任务需先完成或停止。

本次集成测试使用本地协议服务器，覆盖图片字节返回、原图 multipart 上传、视频提交、`pending` 轮询、重启继续、组件导出与密钥撤销；不会将协议测试称为新的付费模型生成验收。
