# 对话办事入口

固定入口把需求、材料、流程执行和结果放在同一段对话中。默认先寻找已保存的流程，匹配可靠时冻结其版本并执行；没有合适流程时调用已有零代码编排器，保存真实工作流后执行。用户也可以指定流程或明确选择“创建新流程”。

## 使用体验

- 主导航常驻“对话办事”，其他页面提供同一个快捷入口。输入框支持拖放、粘贴图片以及选择图片、音视频、PDF、Word 和文本附件。
- 自动选择、指定流程、创建流程放在输入框上方；普通用户无需配置工具。既有高级对话仍可使用原来的工具、模板、分支和上下文整理能力。
- 每条需求都有独立执行卡：先展示匹配/编排状态，再展示真实 DAG 的节点状态、连线、失败位置和执行产物。审批、补充资料和取消直接复用任务接口。
- 执行中节点显示呼吸光圈与旋转指示，已完成前序通向正在执行节点的连线显示流动效果；完成时短暂高亮。等待确认、失败和取消采用静态状态，不暗示任务仍在运行。更新只修改节点状态，保留动画进度、焦点和图内滚动位置；系统“减少动态效果”设置会关闭动画。
- 低置信度或信息不足时给出说明及候选按钮，不凭空猜测参数或悄悄执行。完成的流程可继续使用，也可在原画布编辑、导出和分享。
- 对话、附件引用、路由决定、流程快照和 run ID 都持久保存。刷新、切换页面、重启服务不会丢失关联；重复发送同一请求不会重复执行。

## 与现有功能的关系

复用 Conversations、Artifacts、零代码编排器、版本化工作流、运行调度器和已有审批机制。匹配模型只输出目录中的工作流标识与业务输入，不能更换节点、工具、权限或凭证。匹配阶段不执行业务工具。素材内容作为不可信材料处理。

匹配目录会展开固定版本的循环和子工作流，展示其中实际工具、用途和输入连线；已接入的修图操作不会因藏在循环内而被误判成缺少能力，也无需用户另行提供接口定义。

附件保存为本机 artifact ID。文本/PDF/DOCX 可提取文字；图片与支持的音频在模型请求边界转换为对应接口的内容块。视频等较大材料通过已接入的处理流程消费 artifact ID。上传成功不等于模型能理解该格式：不支持的模型/接口明确报错，不用文件名伪造识别结果。单文件上限 50 MB，每条最多 8 个附件、合计 100 MB；直接模型输入合计上限 12 MB。

## 集成验收范围

规划输出在进入节点开发前会校验 JSON、字段约束和工作流依赖。首次规划最多尝试三次：将无效草稿和具体约束一起反馈给模型，纠正后才进入下一步；纠错记录和进度支持重启恢复。持续无效时停止并保留简短诊断，不会放宽约束或执行无效草稿。单步 `timeout_seconds` 必须大于 0 且不超过 3600 秒；总任务时长使用 `limits.wall_time_seconds`，异步远端任务使用持久轮询。

批量修图等 `foreach` 步骤中，`input.items` 是待处理集合；其他显式传入的字段（例如 `input.edit_prompt`）会传给每个子流程，用 `$input.edit_prompt` 读取。`$input.item` 和 `$input.index` 始终由循环产生。子流程保留自己的默认输入，不会隐式继承父流程中未传入的数据。

覆盖自动匹配与执行、歧义澄清、指定流程、零代码生成/保存/执行、版本固定、附件提取与媒体请求、审批恢复、重复提交、队列和重启恢复，以及桌面和移动布局。模型选择测试使用明确标注的本地协议 fixture，不将其称为付费模型实测。

## 本轮结果（2026-09-20）

- 全套 **138 项集成测试通过**（183.09 秒）。其中本入口 10 项覆盖后端与真实 Chromium 操作；补充了历史超过 200 条时的旧任务恢复，以及路由上下文过大时不调用模型的场景。回复排版检查同时验证不执行材料中的 HTML。
- 已连接真实模型执行两次通知材料验收：一次按名称复用，一次仅描述需求、不给流程名称。后者从 37 个已保存流程中选中「通知整理与行动清单」v1，实际运行“读取附件 → 提取事项与时间 → 保存文件”，输出包含报名截止日期和接送待确认项。没有调用消息发送等外部写入接口。
- 真实语义匹配的会话、匹配运行、业务运行及产物编号仅保留在本机验收记录中；产物可在本机预览的任务或对话记录下载。
- 浏览器验证上传、执行中节点、完成后的历史状态、结果下载入口、刷新及服务重启恢复、打开画布、常驻按钮和 390px 窄屏布局。真实验收无前端异常。截图与日志保存在本机 `.eah/chat-workspace-20260920/`。
- 两个 Python 包构建成功；在独立 wheel 环境运行 HTTP 上传、匹配、附件读取、保存结果，并验证 PDF 依赖和静态资源。macOS 桌面包重建且 smoke 通过。Ruff、JavaScript 语法、22 份契约导出及中英文文档链接检查通过。

音视频内容理解需相应模型或媒体接口，图像三协议及音视频请求结构本轮使用本地协议 fixture 验证；本轮真实模型验收使用通知文档。窄屏浏览器检查不等于 Android/iOS 真机验收。上传与直接模型输入有不同大小上限，详见上文。
