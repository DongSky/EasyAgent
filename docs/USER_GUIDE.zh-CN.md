## 安装与启动

### 从源码启动

需要 Python 3.11+、[uv](https://docs.astral.sh/uv/getting-started/installation/) 和可访问本机服务的浏览器。建议 Python 3.12；Node.js/Rust 仅在相应代码开发和完整集成测试时需要。

```sh
uv sync --locked --extra app --python 3.12
uv run --extra app easyagent studio
```

打开 [工作室](http://127.0.0.1:8765/)。终端保持运行；按 Ctrl+C 可停止服务。下次使用同一数据库路径启动，可读取已保存的配置和记录。关闭浏览器不会停止 Python Hub，但会停止这个浏览器的系统通知接收。

可用启动选项：

```sh
uv run --extra app easyagent studio --port 8770 --database .eah/my-project.db --no-browser
```

此时手动打开 `http://127.0.0.1:8770/`。不同数据库代表独立工作区；更换数据库不会自动复制连接密钥。`serve` 提供同一 API/Studio，但不自动打开浏览器；`life` 额外挂载生活应用。

已有 macOS 本地开发包的环境可运行 `.eah/build/desktop/EasyAgent.app`；这个路径是构建产物，不保证每份源码中都有。它尚不是已公证的公开安装包。Windows/Linux、Android/iOS 的验收范围见本指南末尾。

### 不用密钥的第一条流程

保留服务终端，在第二个终端运行：

```sh
uv run easyagent run examples/first-workflow.json --url http://127.0.0.1:8765
```

预期两个步骤成功，输出 `hello.json` 产物。到「任务」找到本次运行，点「查看结果」展开详情，再下载文件。这条流程使用回显工具；不联网、不调用付费模型，也不证明语言理解能力。默认 `mock` 的图像输出是占位图。

## 认识工作区

- **对话办事**：发送需求和附件，自动选择或创建流程，在对话里看进度和结果。
- **我的助手**：描述需求、在画布编排、管理已保存助手与流程。
- **任务**：运行记录、待确认事项、失败详情、定时安排。每次执行有独立记录。
- **资料**：供助手检索的材料，以及经确认保存的偏好与事实。
- **设置**：模型与服务、Skills、扩展、经验改进、诊断备份和开发者接口。

“助手”保存用途与处理方式；“工作流”列出实际处理步骤；“任务/运行”是某次输入的执行记录；“节点/工具”是步骤调用的能力；“产物”是生成并可下载的文件。保存流程不等于执行，执行完成不等于外部消息已经送达。

工作室的“使用指南”弹窗提供简短引导；`/docs` 是接口参考，完整操作说明以本文件为准。

## 连接模型与搜索

### 连接自己的模型

1. 打开「设置 → 模型与服务 → 连接模型」。
2. 填写便于识别的连接名称、服务地址、准确的模型 ID、接口类型与自己的 API Key。
3. 按供应商接口选择 Chat Completions、Responses 或 Messages；模型名称不能决定它一定支持哪种接口。
4. 点击「读取可选模型」获取当前服务的模型 ID，也可以直接填写。读取列表不发起生成；部分服务不提供列表。
5. 选择「保存并测试」验证调用，或「仅保存」稍后再用。测试可能产生模型费用；失败时按错误修改配置。

服务地址按供应商给出的 API 基础地址填写，避免把完整 `/chat/completions` 请求地址再当作基础地址。不要仅复制其他人的模型名称而沿用自己的不兼容接口。

设置中保存的模型密钥在本机凭证库加密存储，重启恢复；不会回填到表单或放进工作流导出包。测试成功只证明一次连接调用通过，不能保证所有参数、任务质量和账户额度。

### 编辑、删除与选择模型

「已连接模型」的每一行都有「编辑」「删除」。编辑时密钥留空会保留原值；修改服务地址时需重新填写密钥。连接名称是工作流引用的标识，不能改名；需要另一个名称时新建连接。通过配置文件或扩展注册的模型会显示来源，需在原配置中修改。

在同一页面选择「默认处理模型」，供使用“自动”的后续任务优先使用。「对话办事」的输入框上方可选择具体模型，已创建对话也能在本轮完成后切换；创建助手时可选择「构建工作流的模型」。模型选择会保存，刷新页面仍然有效。对话和构建列表仅提供支持结构化决策的模型；生图与向量模型由工作流对应的步骤使用。

删除连接会移除本地加密凭证，并停用由它派生的图片节点。历史记录和工作流仍保留，引用已删除连接的地方会提示不可用，需要重新选择或生成流程。正在使用连接的任务需先完成或停止。修改默认模型或对话模型不会改写已保存工作流里的模型步骤。

### 先创建，稍后连接

没有任何模型时，仍可在「对话办事」发送需求和附件，或在「创建助手」保存用途。系统先保存任务，显示「等待连接」，提示添加支持结构化输出的编排模型；此时没有调用模型，也没有生成可执行流程。

已有编排模型但缺图片等执行服务时，会保存能够规划的步骤草稿和待接入清单，例如“支持接收原图并返回编辑成品的图片模型”。草稿与可执行流程分开保存，不会把占位能力当作成功接入。

点击「去连接模型或服务」补齐配置，再返回原对话。Agent 会检测连接变化，重新检查模型与工具目录，把草稿绑定到实际接口，验证通过后继续原任务。也可以点击「识别连接并继续」或发送补充说明，原附件无需重传。只添加连接而不返回对话，不会自动执行历史任务；连接没有变化时不会反复调用模型。已停止的任务不会自行恢复。

等待期间可切换编排模型。已有助手可从「我的助手」重新打开，点击「已连接，继续生成」。刷新页面或重启服务仍能读取任务和草稿；外部操作继续遵守执行确认。

### 配置 TinyFish 搜索

在同一页面的「联网搜索」卡片填写自己的 TinyFish API Key，选择「保存连接」或「保存并测试」。可以更换密钥、测试当前连接；有已保存密钥时留空表示保留，不是删除。

默认工具名为 `search.tinyfish`。设置中的用户配置优先于同名演示/启动配置；高级选项可改用指定环境变量或自定义网关。搜索结果包含链接与摘要，助手仍需核验来源，搜索成功不等于内容必然正确。

### 添加其他 API 或 MCP

「添加搜索 / API」支持手动 HTTP 接口和 OpenAPI 3 JSON 文档导入。先预览操作，再选择需要的接口；密钥放在凭证字段或凭证别名中。常见 JSON 接口可直接配置，复杂媒体、流式或自定义签名协议可能需要原生节点或开发者扩展。

「通知与日历」用于添加消息/日历服务；「MCP 服务」可连接远端 MCP、完成其授权、刷新能力并决定开放哪些工具。发现工具不等于自动授予使用权限。零代码助手会从已经接入且获准的能力中选择；不会替用户创建第三方账号。

## 自然语言创建助手

### 示例：整理学校通知

先连接真实语言模型，再进入「我的助手 → 创建助手」，填写名称与需求，例如：

> 把我提供的学校通知整理成行动清单。每项列出事项、负责人、截止时间、需准备物品和原文依据。缺少的信息写“待确认”，不要编造。最后保存一份可下载的清单。

1. 点击生成流程，等待构建完成。
2. 查看步骤、依赖和需要的输入，确认它们符合目的。可打开完整定义或转入画布。
3. 放入一段测试通知，试运行。
4. 在任务中检查每一步结果、补充信息和最终产物。
5. 确认输出可用后保存助手；以后更换输入即可复用。

判断是否通过时，检查清单是否覆盖原文所有行动、日期是否有依据、缺失字段是否保留为待确认、产物是否确实可下载。不要只看最后一句“已完成”。

构建阶段生成并校验计划，不执行实际发送、预约等业务操作。如果能力不足，会要求补充条件；应先接入必要服务再重新构建。修改需求后要重新生成，防止运行旧计划。预览、运行和导出对应同一份保存流程。

模型连接要支持真实构建所需的结构化输出；内置 mock 不可用于自然语言编译。构建和后续运行都是独立的可追踪任务，关闭窗口不等于取消它们。

## 在画布上连线

适合已经知道“先做什么、再做什么”的任务。

1. 在「我的助手」打开画布，命名流程。
2. 从工具/节点库加入步骤，在表单中填写参数。
3. 从上游输出端口拖到下游输入端口。数据连线建立字段引用，并建立先后依赖；单纯执行依赖不自动传递全部数据。
4. 点击校验，修正缺失输入、类型不匹配或循环依赖。
5. 保存后运行，在任务记录中逐步检查结果。

最快体验：导入仓库中的 `examples/first-workflow.json`，查看“回显 → 保存产物”的连线，修改初始输入后另存并运行。

画布提供移动、缩放、平移、自动排列、撤销/重做和断线。无相互依赖的步骤可并行。条件当前支持指定字段等值判断；`foreach` 对有界数组运行子流程，不提供无限 `while`。常用节点包括工具、模型、Agent、数据整理、检索、产物、循环、子流程、确认和补充信息；目标修复由单独的目标控制功能管理。

复杂参数、重试、补偿和子流程设置放在高级配置中。生成后的流程可在画布另存；手工改动不会自动覆盖原助手的生成版本。

## 从代码运行

已经启动 Hub 后，可直接运行仓库例程：

```sh
uv run python examples/getting_started/python_client.py
node examples/getting_started/javascript_client.mjs
cargo run --locked --manifest-path sdk/rust/Cargo.toml --example demo
```

后两条分别需要 Node.js 20+、Rust/Cargo。默认连接 `http://127.0.0.1:8765`。切换服务地址时设置 `EAH_URL`：

```sh
# macOS / Linux shell
export EAH_URL=http://127.0.0.1:8770
```

```powershell
# Windows PowerShell
$env:EAH_URL = "http://127.0.0.1:8770"
```

SDK 的等待方法会在需要批准、补充信息或核验时返回暂停状态，不会自动同意。`easyagent run` 不读取 `EAH_URL`，请使用 `--url`。完整开发方式见[开发指南](DEVELOPER_GUIDE.zh-CN.md)。

## 查看任务与安排通知

### 处理任务状态

「查看结果」在对应记录下面展开，再点一次收起。页面支持筛选与刷新；产物在展开区域预览或下载。

- **等待执行 / 执行中**：服务继续处理，查看步骤和事件判断是否在等远端结果。
- **等待确认**：检查具体工具、目标和参数后同意或拒绝。
- **等待补充信息**：填写任务提出的问题，然后继续同一运行。
- **需要核验**：外部操作可能已发生，但本地没有可靠回执；先核对外部结果再提交依据，避免重复发送或下单。
- **成功**：流程完成；外部通知的实际投递状态还需到连接页面查看。
- **失败 / 已取消**：查看失败步骤和原因；取消不会撤销已经发生的外部操作。

### 定时安排

先保存并手动验证流程，再进入「任务」中的定时安排，选择流程和执行时间。按每天、工作日、每周等模板配置，并确认时区。服务必须运行；停机错过的触发采用合并补跑，不会无限补发全部历史次数。

定时启动也不能绕过写操作审批；无人值守的外部操作需要明确的部署策略。长时间等待或睡眠由持久调度处理，不需要自己保持一个模型请求。

### 系统通知

打开「设置 → 模型与服务 → 通知与日历」，选择「系统通知（当前设备）」：

1. 点击「允许系统通知」，完成浏览器授权。
2. 使用默认名称或填写自己的名称，保存连接。
3. 点击「保存并发送测试通知」或已保存连接的「发送测试通知」。

不需要地址或 API Key。保存后助手与画布可使用这项能力，输入通知内容和可选标题。工作流使用时仍经过写操作审批。

接收位置是**当前绑定浏览器所在的设备**，不是 Hub 服务器。请保持工作室页面打开；关闭页面或手机挂起后留队，重新打开再领取。换浏览器、端口或清除站点数据后要重新绑定；旧流程固定的旧连接版本不会跟着改变。

下方记录区分等待接收、发送失败、需核验和“已提交系统”。后者表示浏览器接受请求，不能证明横幅已显示或已读；系统勿扰模式可能隐藏提示。应用内浏览器不支持时请使用兼容的系统浏览器。目前不提供 iOS 原生通知桥接或后台 Push。

### 消息与日历

可选 Webhook、Telegram、Slack、Discord、飞书和 CalDAV，使用自己的服务地址/凭证/收件人。只在服务确实支持幂等去重时开启安全重试。通知进入持久队列，单独记录投递结果；CalDAV 写入事件不等于已经提供完整双向日历同步。

## 对话、资料与记忆

打开「对话办事」，或其他页面右下角的同名入口。新建对话，描述需求，使用「添加附件」、拖放或粘贴图片提交材料。先在设置中连接自己的模型和需要的服务，使用时不必逐项选工具。

输入框默认「自动安排」：匹配到合适的已保存流程后，以固定版本执行；没有合适流程时，编排、保存并运行新流程。需求不清楚或缺少必要参数时会先询问。也可在下拉菜单指定已有流程、选择「创建新流程」或「仅对话」。文件上传成功不代表所有模型都支持识别它的内容。

每条需求下方显示实际执行图：正在进行、已完成、失败或等待确认。点击节点展开步骤与结果，在原位置处理审批、补充信息和下载文件。「在画布中打开」可继续编辑、导出或分享。停止不会撤销已发生的外部操作；运行期间发送的后续消息按顺序排队。

左侧保留历史和搜索，手机点「历史」展开。刷新或重新启动同一工作区后，可以继续查看材料、运行和结果。附件每条最多 8 个，单文件最多 50 MB，合计最多 100 MB；直接模型输入合计最多 12 MB。文本、文字型 PDF、DOCX 可以提取文字；扫描件需 OCR，音视频需对应模型或处理接口。PDF 最多处理前 100 页、最多 60000 字符，长材料请拆分。

「高级对话」保留选择模型及允许能力、运行中转向、分支和生成来源摘要等操作；工作流执行的后续消息不会直接改写正在运行的步骤。摘要保留原始记录，不替代永久记忆。更多说明见[对话办事与附件](CONVERSATION_WORKSPACE.md)。

在「资料」添加需要检索的材料，选择用于检索的资料空间；已有知识库可使用词法、向量或混合检索。向量检索需要兼容的 embedding 模型。检查答案引用，未命中材料不能当作证明事实不存在。

「记住的偏好」保存明确确认过的习惯和事实，使用命名空间控制访问。更新/合并有版本或原始值校验；工作流 checkpoint 只用于执行恢复，不是知识库。

## 安装技巧和扩展

### Skills：告诉助手如何做

在「设置 → 使用技巧」选择内置技巧、导入 Markdown/JSON/文件夹，或从 GitHub 获取。预览说明、文件与固定来源版本后安装。也可描述一种做事方法，让模型生成候选，再预览安装。

技巧可包含 `SKILL.md` 与参考文本。对话开头输入 `/技巧名称` 使用；自动构建器可发现已安装技巧。支持查看、导出、停用、回滚和来源更新检查。

安装技巧不会执行附带脚本，不会自动授予终端、网络或其他工具权限。Hermes 等来源的技巧可以复用文本格式，其专有工具和依赖仍需适配。

### 扩展：提供实际能力

在「设置 → 扩展」导入源码包或配置可信目录来源，查看工具、设置、权限和版本，然后安装。已安装能力会出现在助手、节点库或扩展界面中；可以更新、切换版本及导出。

纯 JavaScript/WASM 扩展用于受限计算；Python/Node/Rust 进程扩展需要明确的源码信任及相应运行环境，拥有宿主账户权限。签名或文件摘要检查不能替代对源码的信任。安装器不会自动运行任意依赖安装脚本。

扩展设置中的本机浏览器/终端默认关闭。启用前配置允许的站点、工作目录与限额；这些限制不等于操作系统沙箱。

## 图片、视频与音频

能力库默认包含文字生图、参考图编辑、视频提交、视频等待和参考图上传五个独立节点。点击「选择服务连接」绑定已保存的地址和凭证，无需手填 schema。视频提交和等待是不同节点；只有真实完成回执才代表生成结束。详见[默认媒体节点](DEFAULT_MEDIA_NODES.md)。

1. 在模型与接口目录选准确的模型和操作，核对它使用的协议与参数。
2. 连接自己的服务凭证，把操作添加到节点库/画布；同步目录不会自动开始生成。
3. 填写提示词等参数。参考文件字段可上传图片，或使用同一 Hub 中已有产物引用。
4. 执行后在任务详情预览或下载产物。异步视频通常分为提交、等待/查询和获取结果；必要时显式调用取消接口。

模型名不足以推断接口。文本、图像编辑、语音上传、视频轮询的字段不同。对话附件通过独立原始上传接口接收，单文件上限 50 MB；普通 JSON 请求仍限制 2 MB，外部媒体接口的请求/响应另有各自限制，不能据此认为大型视频都能处理。远端临时链接可能过期；跨 Hub 分享引用时需要重新上传输入产物。

语音设置可配置转写和合成模型；高级对话中录音最多 60 秒、上传最多 1 MB，转写后先检查文字再发送。回复可合成并播放。这不是实时双向语音通话，麦克风权限及真实账户仍需自行测试。

真实验收中 `gpt-image-2.5-flare` 已生成 Q 版表情，`doubao-seedance-2-5-260628` 已将该图生成约 4 秒的 720×720 动画。当前服务需要先上传参考图取得 HTTPS 地址，并在查询时处理 `pending` 状态；请求关闭音频后，实际视频仍含音轨。详见[多媒体验收](MEDIA_ACCEPTANCE.md)，其他服务和模型仍需分别实测。

## 自动修复与经验改进

创建助手时可开启“自动检查结果，修复或补充步骤后继续”，设置最大修订次数，并选择是否允许新增纯计算代码。

执行器会运行当前计划、检查产物、生成必要的修订，再验证新计划。每个版本、理由和子执行都有记录；可以在任务页反馈问题、暂停后续续跑或继续。可复用版本保存在 `goal_<run_id>.plan`，能打开、编辑或分享。

目标、已授权能力与预算不会由修复模型自行扩大；重复方案、预算耗尽或无法完成时会停止并报告未完成。改变过的外部写操作不会盲目重放。语义评价可能判断错误，关键数字、字段和回执应由开发者设置确定性检查。

“经验改进”是另一条链路：从运行生成技巧/策略候选，执行评估，再由人批准发布或回滚。自动复盘默认关闭，有每日预算；自动修复不等于自动安装任意插件或训练模型。

## 复用、导出与分享

- **流程 JSON**：保存步骤、输入、布局及引用。接收端仍需要可用的模型、工具和数据。
- **助手导出 ZIP**：包含流程、输入、依赖说明和 Python/JS/Rust 客户端；不是独立服务器安装包。
- **节点/组件包**：用于复用固定版本 HTTP 能力或子流程。导入前预览并绑定接收端凭证。
- **扩展源码包**：包含代码与声明的权限/依赖，不包含本机凭证库或运行历史。
- **完整工作流包**：打包流程快照、布局、固定定义及可打包的源码扩展。MCP/连接器、知识材料、媒体输入和密钥需要按依赖说明重建或绑定。

在画布、已保存流程或自动构建结果中选择“分享完整工作流”。接收方先预览，配置自己的模型和凭证，明确安装所需扩展，再导入独立副本。导入不会自动运行。字面写进提示词、参数或 Skill 的个人信息仍可能被分享，导出前应检查内容。

同一 Hub 内可用“用作子流程”复用保存的版本。更新组件不会静默改变已提交任务；要采用新版，显式修改引用并保存新版本。

## 生活事务管家

使用 `uv run --extra app easyagent life`，打开 `/life`。需要改端口时可同样传 `--port` 和 `--database`。

1. 选择搬家、旅行、学校通知或维修模板，输入主要日期，建立草稿。
2. 粘贴原始材料；模型可提取候选事项，人工检查日期与来源后确认加入。
3. 指派负责人，记录等待对象或阻塞原因。
4. 日期改变时调整尚未完成事项；已完成事项与历史保留。
5. 记录费用、资料和完成凭证，再办结事项。未完成依赖会阻止后续事项直接办结。

可先用合成模板体验，无密钥时不会伪称发生了模型推理。这里的本地提醒首先是待处理清单；配置系统通知也不会自动把所有生活事项接入通知，需要工作流显式调用连接能力。

目前记录家庭分工，不提供多个家庭账户的实时同步；尚未自动接入邮箱、OCR、支付、电话、商家预约或真实代办。

## 保存数据与跨平台使用

源码默认数据库为 `.eah/hub.db`，同目录的 `.secrets.key` 保存凭证解密所需密钥。保护这两个文件；只复制 SQLite 主文件可能漏掉 WAL 中的数据。资料、提示词和模型输出也可能含个人信息。

推荐使用「设置 → 诊断与备份」或 CLI 的一致性加密备份。CLI 先通过自己的安全方式设置 `EAH_BACKUP_PASSWORD`（至少 12 个字符），然后运行：

```sh
uv run easyagent backup .eah/my-backup.eah --database .eah/hub.db
uv run easyagent restore .eah/my-backup.eah --database .eah/restored.db
uv run --extra app easyagent studio --port 8770 --database .eah/restored.db
```

恢复目标必须是尚不存在的新数据库。备份包含数据库及凭证解密密钥，不会自动收集任意外部插件源码、工具链、环境变量或远端文件；这些部署依赖要另外保留。诊断命令是 `uv run easyagent doctor --database .eah/hub.db`。

手机可连接你自己的 HTTPS Hub。Python 完整执行、受信任代码与长期后台任务由 Hub 承担；手机内置 Rust 核心只覆盖声明式执行子集。已测试 iOS 模拟器离线流程，Android APK 和真机后台验收尚未完成。没有 Docker 依赖，也不承诺手机系统允许常驻。

远程部署需服务端设置 `EAH_TOKEN`、配置 HTTPS 入口和访问控制；这是单用户令牌，不是多租户账号系统。浏览器中的 Hub 访问令牌只保存在当前页面内存，刷新后可能需要重新输入。

## 常见问题

**页面打不开或端口占用。** 检查启动终端是否仍运行、地址端口是否对应；使用新的端口和数据库。不要为了教程停止其他应用的服务。

**连接报 401/403、404 或模型不可用。** 分别检查密钥/权限、基础地址/协议、准确模型 ID 和账户可用模型。测试成功不代表任意模型专有字段都受支持。

**搜索仍在用旧密钥。** 到“联网搜索”查看凭证来源；设置中保存的密钥优先于同名环境配置。更换后测试一次；如果选择环境变量，要重启读取该变量的服务进程。

**没有生成工作流或导出为空。** 确认使用真实模型、构建任务成功、需求没有在构建后修改，以及必要 API 已接入。未构建或过期的助手会拒绝导出；不要把需求文字当成已经存在的流程。

**任务一直等确认/输入。** 展开该任务处理具体请求。这是持久暂停，不是卡死；SDK 的 wait 也会返回这一状态。

**结果不符合需求。** 查看每步输入输出与最终文件，给出具体缺项和可检查的完成标准；可以开启目标修复。修复耗尽预算后仍须如实视为失败。

**系统通知没有弹出。** 检查支持情况、浏览器授权、系统通知/勿扰设置、页面是否打开及接收浏览器是否匹配。`queued` 不等于送达，`submitted` 不等于可见；不确定状态先核验，避免重复通知。

**媒体 503 或没有视频。** 保留提交回执，确认是否产生远端任务 ID。未得到 ID 不能宣称生成成功；结果未知的写操作不要重复提交。取消本地运行不保证供应商已取消计费任务。

**分享后不能运行。** 在导入预览中逐项绑定模型、API 凭证、MCP、通知、扩展、知识空间及媒体输入。原 Hub 的产物 ID 和本地路径不会自动变成接收端文件。

**安装依赖失败。** 先使用建议的 Python 3.12，检查 uv、网络和平台轮子/本机构建工具。全套测试另外需要 Node、Cargo、Chromium；尚未实机验证的平台不能承诺一键可用。

需要开发自定义能力时，继续阅读[开发指南](DEVELOPER_GUIDE.zh-CN.md)。当前版本的交付证据与未完成项目见[最新交付记录](NEXT_DELIVERY.md)，不要将旧阶段的测试数量当作当前总数。
