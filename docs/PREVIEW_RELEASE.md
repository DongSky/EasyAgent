# 0.1 公开预览说明

**简体中文** | [English](PREVIEW_RELEASE.en.md)

当前版本适合作为第一个公开源码预览版，供个人使用、搭建流程和反馈问题。版本仍为 `0.1.0 preview`，不代表稳定生产版，也不表示已经发布到 PyPI 或其他平台。

## 可以从这里开始

- [关键词搜索 → 生成提示词 → 生图与来源记录 → 汇合交付](GETTING_STARTED.zh-CN.md)：真实业务案例，支持多个输入和并行分叉。
- Python SDK 和 CLI 可以在本地直接执行；HTTP 服务、独立 Agent App 和远程客户端按需安装。
- 节点是一个独立操作；工作流保存步骤图，显式 `Subflow` 创建子运行。运行保留审批、重试、产物和恢复记录。

`examples/first-workflow.json` 保留作无需密钥的安装检查。以前重复的清洗/问候玩具脚本已移除，开发教程统一指向搜索生图案例。正式测试 fixture 继续保留在测试与验收代码中，不自动填充日常工作区。

## 已验证与边界

2026-09-20，本机完整集成测试 **165 项通过**，包含多输入、分叉汇合、节点与子流程边界，以及归档后重启继续执行固定版本的场景。Python SDK、App、HTTP 客户端分别构建并隔离安装验证。跨平台 CI 已配置；这份记录不代替各平台的实际运行结果。

本轮外部服务协议采用本地 HTTP fixture 验证，没有重新调用收费模型；过去真实生成的图片与视频见[媒体验收记录](MEDIA_ACCEPTANCE.md)。桌面安装包未在本轮重建，优先使用源码安装路径。

`Module.forward` 的多输入和并行依赖可以直接表达；符号值的原生 Python `if` 尚未实现，条件路由使用 `Step.when`，互斥分支自动汇合仍需后续设计。分布式高可用、多租户强隔离和完整移动端运行时不在此次预览承诺范围。

## 保持工作区干净

实验和验收请使用单独的数据库。已有测试条目可以[归档](NODE_LIBRARY.md#清理本地实验条目)：从列表和自动编排候选移除，保留历史与固定引用。仓库忽略 `.eah/`、数据库、环境密钥及构建缓存；本地备份和清理清单不进入分发包。
