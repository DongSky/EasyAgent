# 两批精简与编排改进（2026-09-21）

这次修改沿用现有运行器、依赖图、版本快照和回执，没有添加另一套调度引擎。

## 第一批：减少重复读取和无效传输

- 每次执行节点从两次完整运行读取，改为一次读取冻结输入与已完成输出。
- 调度轮询只查询运行状态，到终态再读取结果；对话历史一次读取所有任务状态，消除逐条查询。
- `GET /v1/runs/{id}?progress=true` 只返回进度、依赖、审批、重试、输入请求和子运行等控制信息。展开详情或运行结束后读取完整结果，原接口默认行为保留。
- 前端使用后端提供的阶段定义，避免两份状态表分别维护；绑定流程时去掉一次重复 prepare，提交前的冻结与校验保留。

本机同一个已完成头像运行的 JSON 编码测量：完整响应 545,335 字节，进度响应 10,454 字节，减少 98.1%。20 次只读采样的中位数：原两次完整读取 5.560 ms，执行输入读取 1.509 ms，状态读取 0.574 ms。这是该数据库和样本的观察，并非所有工作负载的承诺；审批参数等需要展示的内容仍保留。

## 第二批：按任务构造流程，按实际边界拆节点

- 编译器与自主 Agent 共用构造规则：一个可复用业务任务保存在一个完整流程里；相同重试边界内的解析、过滤、汇总和格式化可以合成一个经过测试的纯计算节点。
- `ModelRequest.context` 和 `AgentConfig.context` 接收结构化数据及普通 `$ref` 引用，由运行时一次转成用户上下文。无需为序列化单独增加 `core.to_text` 节点。旧节点仍可运行，已保存流程不自动改写。
- 独立分支由工作流调度；节点内部需要判断或迭代工具时才用 Agent，只有足够独立的实质任务才委派。外部写入、审批、等待和回执继续保留独立边界。
- 多候选的大流程目录先用操作摘要发现候选，再读取候选固定版本的完整连线和参数，确认适配后才执行；不适配时仍可创建新流程。小目录、单候选与用户明确指定流程仍只匹配一轮。
- 仅对自动安排、自动执行选中的失败流程，接入一次现有编译修复路径。已完成写操作必须保持输入和依赖定义一致才能复用回执；更改写入、业务输入或嵌套写操作时继续拒绝盲目重跑。明确指定版本、临时服务故障和预算/配置问题不走这条自动修复路径。
- 删除保存时无条件添加 `message` 和空附件字段的行为。对历史流程仅忽略显式契约以外、调用者没有提供的空运行时占位字段；不修改保存版本，不忽略未知业务参数。对话、命名工作流 API 和 Agent 的流程调用遵守同一输入规则。

同一头像目录样本中，两轮匹配合计 15,258 输入 token，原一次完整目录匹配为 22,172，减少约 31.2%，代价是增加一次模型往返。这不是总任务 token 或费用降低比例；旧头像流程仍包含较大的网页上下文及转文本节点。

## 真实产品验收

所有模型调用使用已配置的真实服务，离线协议夹具测试另行记录。

1. **自然语言生成并合并操作**：隔离数据库仅接入文本模型，不预置业务节点或工作流。浏览器输入清洗客户名、过滤退款、汇总两份 CSV、输出 JSON 和中文报告的业务要求，没有提供节点拓扑。产品生成、测试并发布计算节点，保存一个三节点流程：计算 → 两个独立文件节点。Alice=17、Bob=10、Carol=8，总金额 35；没有转文本节点，也没有委派模型算数。
2. **换数据复用**：同一保存版本换成另一组 CSV，产物为 Dana=12、Eli=9.75、Finn=7，总金额 28.75。节点和流程版本未变，浏览器无脚本错误。首次复用暴露了多余运行时字段与严格输入契约冲突的问题，修复后在原保存版本上复验通过；失败记录保留。
3. **节点内部编排**：一个复核 Agent 节点安排两个子 Agent，实际模型执行时间重叠；报告指出 12×3=36 以及周六/周日矛盾。本次运行树共 14 次模型调用；不把它描述为比所有先前运行更省 token。
4. **原句头像任务**：仅发送“从网上搜索游戏里若娜瓦的形象，然后生成一个若娜瓦的Q版头像”，无附件或补充指令，保持自动安排、自动模型和自动执行。产品复用已有流程，搜索身份和来源，下载参考图，生成 1024×1024 PNG。业务流程约 190 秒，浏览器预览和下载通过，下载字节与产物一致；另对参考图与结果做了人工视觉检查。

头像此前一次运行因搜索结果不相关、下游收到空 URL 而失败，未计为通过；这次成功没有触发自动修复。新增的修复路径由回归测试证明，尚不能据此声称它通过了真实头像失败恢复验收。旧保存流程的搜索稳定性及网页上下文大小仍有改进空间。

原始证据、数据库、截图、图片和视频保存在被 Git 忽略的 `.eah/` 与 `output/`，公开文档不包含连接地址、凭证和本机身份信息。

## 复验入口

需安装浏览器依赖并事先配置模型；真实验收会调用服务：

```sh
uv run python scripts/live_agent_acceptance.py --database .eah/hub.db --model gpt --group-operations --skip-delegation
uv run python scripts/live_agent_acceptance.py --database .eah/hub.db --model gpt --only-delegation
```

第一条从业务要求重新生成流程并更换数据复用。默认模式仍验收显式要求的并行分支和汇合，`--only-delegation` 验收节点内部委派。

离线回归覆盖原消息与原生 context 等价、上下文单次注入与保护、候选冻结版本、执行前验证、平行分支与子流程结果、写回执复用和拒绝、一次修复上限、严格输入契约兼容、进度控制信息及批量读取。协议夹具不代表真实模型质量。
