## 4. 验收发现并修复的问题

第一次头像验收中，旧流程把空网址交给下载工具。自动修复生成的草稿改动了已完成的操作，原有回执保护在执行前正确拒绝，但构建阶段已经把草稿标为有效，模型无法收到这项验证反馈。

修复将**相同的回执检查前移到构建验证阶段**，错误草稿继续由现有修复循环处理，验证通过才保存。执行前仍然检查回执，不放宽工具权限、不重复已完成的写操作。验证无法通过的对话现在标为失败。已有历史记录中错误标为“成功／待澄清”的任务仍能从页面重试。

新增回归覆盖删除完成操作、修改操作参数、修改冻结输入；检查无效草稿不发布、修复时写操作只发生一次、以后独立复用仍会执行自己的操作。浏览器回归同时覆盖新旧失败状态的重试。
