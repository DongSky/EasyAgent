## 一个完整工作流必须连接的链路

输入/触发 → 身份与权限 → 上下文组装 → 知识检索/记忆 → 计划与决策 → 模型/工具执行 → 观察/重规划 → 输出/产物 → 评估/反馈 → 可控改进。

贯穿全程：持久化状态、预算、审批、版本、取消、重试、超时、并发、可观测性、凭证和扩展协议。

## 初始版本的真实状态（历史记录，非当前状态）

- 已有可运行实现：SQLite 任务状态、租约、DAG、工具 schema、逐调用审批、恢复、三语言 SDK/进程插件、MCP、Skills、模型适配、基础 Studio。
- 简化实现：只有等值条件的编排；只有 ReAct 的 Agent；只有 substring 的记忆；只有 substring 比对的自进化评估；模型预算只限制轮数；低代码是表单式节点编辑。
- 缺失：统一触发/调度、模型路由降级、预算核算、结构化知识摄取和检索、上下文管理、产物存储、循环/子流程/并行组、显式计划与重规划、运行追踪汇总、数据集驱动评估/改进、可视化能力配置全链路。

## 框架补齐顺序（每项必须有集成证据）

### G1 编排与 Agent

- Workflow 输入参数；安全映射/模板转换；等值条件；有界 foreach 与子流程；并行组；显式审批/延迟；可配置失败补偿。
- Agent 策略支持 ReAct 和 plan/execute/replan；多角色通过 agent 节点+子流程表达；不做无界自治。
- 暂停恢复时不丢失迭代与子任务；工具结果去重；失败/取消传递到子运行。

### G2 上下文、知识、记忆、产物

- 文档内容摄取、分块、来源与版本；词法/向量检索；检索结果可注入 Agent 上下文。
- 持久记忆支持 namespace、来源、过期与删除；明确区别运行 checkpoint、记忆和知识库。
- 上下文保留 system/任务要求与最近完整工具对；截断有事件记录；不保存思维链。
- 文本/JSON/二进制产物独立存储、内容哈希、大小限制、下载接口。

### G3 运行治理

- Run 级模型/工具/输出 token/费用预算；请求前预留，返回后结算；未知供应商用量不能当零成本。
- 按能力绑定模型，临时错误降级到显式配置备用模型；版本与实际使用模型可追踪。
- 定时和 webhook 触发；触发幂等；暂停/恢复；missed schedule 策略明确。
- 运行追踪汇总：步骤、调用、耗时、用量、失败、审批和产物。
- 凭证只允许服务端环境变量或临时内存；插件默认不继承密钥；可选 Docker 隔离模式，未配置容器环境不能声称安全沙箱已验证。

### G4 评估与可控自进化

- 评估集包括输入、期望输出、禁止输出、schema、预期工具等可执行规则。
- 候选通过真实 Agent 执行链路评估；对比同一数据集与当前基线，保留逐案例证据。
- 从反馈和失败摘要生成候选提示词，禁止候选自动扩大工具权限。
- 人工批准发布；新 run 固定版本；回滚；禁止用单个冒烟分数宣称泛化能力提升。

### G5 三种开发方式

- 零代码：描述需求 → 自动选择已接入能力 → 生成和预览实际步骤 → 运行/补充信息/审批 → 保存与导出同一流程；用户无需手动选择工具或技能。
- 低代码：可视节点与依赖、数据映射、条件、循环、子流程、角色协作、触发器与调试。
- 代码：公开 Python 扩展协议，JS/Rust SDK 与插件；高级配置不能成为其他入口的死胡同。
- 统一项目导入/导出和版本格式；不以静态页面或只有文本的按钮代替功能。

### G6 框架验收后才做应用

- 补齐后的框架集成套件和独立 demo 全部通过，再恢复生活事务管家开发。
- 无 key、无 Docker、未运行其他 OS 的检查结果必须明示，不把待验证写成通过。
- 用户易用性与生产长期稳定性还需真实用户任务测试、长稳和故障注入，不由这一轮本地验证代替。

## 当前完成情况

G1–G4 的上述单机能力已经实现并纳入集成测试：有界循环/子流程、计划与重规划、知识/记忆/产物、上下文裁剪、备用模型/总预算、触发、真实 Agent 评估与反馈候选。G5 三种入口已经打通，低代码补充了可拖动和连接端口的节点画布。G6 在框架 23 项基础与补齐测试及 demo 通过后进入应用，随后扩展业务任务与三模式验收。详见 [测试记录](VALIDATION.md)。

旧版表单式零代码只保存单个 Agent 配置，原先验收证明了调用链，不能证明生成了完整工作流。按最新反馈，现已接入模型编译：生成、校验、保存、预览、运行与导出同一份 Workflow，外部 API 调用必须成为显式节点。没有接入必要能力时停止构建并解释原因。已用一个真实模型完成通知整理四步任务；更复杂需求、生成修复和新手易用性尚需扩大验收。

仍有限制：等值条件、有界 foreach、小型本地向量检索、固定可执行断言式评估；没有任意表达式引擎、开放式 swarm、自动训练权重、A2A 全协议或分布式生产能力。ComfyUI 式交互已提供基础节点/端口体验，尚不等于复刻 ComfyUI 全部扩展生态。

只有配置跨平台 CI，没有 Linux/Windows 实际结果；短时负载与进程崩溃测试不能替代 72 小时长稳。多供应商模型质量、图片上传/OCR、首次新手可用性仍未验收；Docker 已排除。
