连线如何传递数据

彩色实线传递具体字段，虚线安排执行先后。连接输入会自动填写引用；类型冲突和循环依赖会被阻止。

依赖填写前一步的名称，例如 step1。参数里可以引用它的输出：

{"text": {"$ref": "step1.text"}}

没有依赖的步骤可以同时运行。条件不满足时自动跳过；遇到需要确认的操作会暂停等待你。

Python

异步 SDK 与内核扩展

from easyagent_client import HubClient

async with HubClient() as hub:
    run = await hub.submit(workflow)
    result = await hub.wait(run["id"])

JavaScript

Node.js 与浏览器接口

import { HubClient } from "./sdk/javascript/index.js";

const hub = new HubClient();
const run = await hub.submit(workflow);
await hub.wait(run.id);

自定义网关或本地调试

密钥会发送到此地址，仅填写你信任的 TinyFish 兼容服务。

使用 OpenAPI 3 JSON。文件上传、流式响应和远程 Schema 引用需通过插件或 MCP 接入。

直接填写的密钥仅本次服务运行有效；重启后需使用服务端环境变量。导出不包含密钥。

鉴权方式从文档读取。OAuth 使用现有访问令牌；Basic 填写 Base64 编码的用户名与密码。不会自动刷新令牌。

直接填写的密钥仅本次服务运行有效；重启后需使用服务端环境变量。导出不包含密钥。

参数位置、读写权限与高级设置

URL 中的 {id} 来自必填输入。GET 的其他输入默认放在查询参数，其他方法默认放在 JSON 请求体。

例如 {"page":"query","X-Region":"header"}。可选 query、header、cookie、body。
